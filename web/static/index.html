// features
Everything you need to
secure your network

Purpose-built for small businesses who need real answers, not enterprise complexity.

Concurrent port scanning
Scan an entire /24 network across hundreds of ports in seconds using Go's goroutine worker pool with configurable concurrency.
Live CVE detection
Every discovered service is automatically checked against the NIST National Vulnerability Database for known exploits and CVEs.
Device inventory
Automatically identifies operating systems — Ubuntu, Debian, MikroTik RouterOS, embedded IoT — directly from service banners.
Risk scoring
Every scan produces a 0–100 security score with critical, high, medium, and low severity breakdowns and plain-English fix advice.
Network monitoring
Continuously watch for new devices appearing or disappearing on your network, with automatic baseline comparison and instant alerts.
Web interface
A clean browser-based UI means no command line knowledge required. Any staff member can trigger a scan and read the results.
